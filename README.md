# 一念木魚

獨立於原版上班鼓勵器的木魚版本。桌面左側為即時收入面板，右側為深胡桃木風格的靜心木魚；窄螢幕改為上下排列。

## 使用方式

直接以瀏覽器開啟 `index.html`，或執行 `npm start` 開啟本機預覽。不需安裝依賴套件。

- 木魚預設每秒自動敲擊一次，可隨時暫停；點擊木魚或空白鍵也可手動敲擊。
- 每次敲擊彈出「功德＋１」，並累積今日次數。臺灣時間跨日重計，隱藏分頁期間不補敲。
- 音效需點擊「開啟音效」後播放，支援音量調整；音效以瀏覽器即時合成。
- 預設工作時間 08:00～17:00，午休 12:00～13:00，月薪新臺幣 35,000 元。
- 薪資按當月所選工作日均分，午休不計工時。未自動扣除國定假日、請假、稅金或保費。
- 敲擊不影響薪資計算；設定、當日敲擊次數分別儲存在本機瀏覽器，使用獨立儲存鍵，不會改變原版設定。
- 圖像為本專案透過圖片生成模型製作的木魚素材，包含於 `muyu.png`，不依賴外部圖片服務。

## 驗證與部署

`npm run check` 執行語法檢查與 12 項薪資計算測試。

推送到新儲存庫的 `main` 分支後，GitHub Actions 會驗證並發布 GitHub Pages。首次在儲存庫設定的 Pages 來源選擇 GitHub Actions。

此版本未修改原始上班鼓勵器，也不使用原儲存庫的部署設定或網址。
